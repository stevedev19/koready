Hanji cream & indigo: style guide

Every color on this page is read live from src/app/tokens.css, so what you review here is exactly what the app will use. Each section shows light mode and dark mode side by side. The contrast report is worked out in the browser from those same tokens.

Colors

Indigo is the primary color: the active tab, key buttons and the slang card. Jade is for icons and highlights. Red appears only for emergencies, "Likely scam" and critical alerts. Amber means "be careful". Neither jade nor green ever means "safe".

Contrast report (WCAG 2.2 AA)

Body text needs 4.5:1. Large text (24px+, or 18.7px+ bold), icons and input borders need 3:1. Ratios are calculated from the tokens when the page loads.

One of your values didn't pass: brand jade #3FA796 is only 2.88:1 on cards and 2.60:1 on the page, so it fails even the 3:1 minimum for icons on cream. On cream I use jade-icon #338A7C for icons and large text, and jade-text #24766A for small text. #3FA796 stays for decoration and on the indigo slang card, where it reaches 4.02:1. Dark mode uses #6FCFBD for all three, which passes 4.5:1 everywhere.

Type

Pretendard for both Latin and Hangul. Sizes are in rem in the app, so system text size and 200% zoom scale everything. Notes never go below 15px. The 13px tab label is the only exception, and it's bold.

Buttons & focus

The last button in each row shows the focus ring: 3px in the focus color, offset 2px. Every button is at least 48px tall. The emergency button is 88px.

Fields & tool switch

The Safety tab gets neutral, higher-contrast surfaces. Field borders use border-strong at 1.5px, which passes 3:1.

Tags, tips, banners

Rain tips use info blue. Dust tips use amber when the air is Bad or Very bad, and info blue when it's Moderate. Tips never use red. Bad and Very bad air both use amber. Red tags are only for critical alerts.

Cards

Card titles have a jade icon and a Korean label in jade-text. The slang card uses indigo, with light jade #8FD6C8 for its labels.

Safety results

Each result has an icon, a written label and a color, so color is never the only signal. "Likely scam" is red, "Unclear" is amber, and "No obvious scam signs…" is deliberately neutral: no jade, no green. The disclaimer always appears next to the results.

Navigation & emergency shortcut

The active tab is solid indigo. The emergency pill is quiet (only its phone icon is red) and sits in the same top-right spot on every screen. It opens this sheet. Numbers were checked against official sources: 119 at mohw.go.kr (ambulance, fire, 24h medical advice) and 112 at korea.net, 2024-03-19 (police, 24h English and Chinese interpretation).
